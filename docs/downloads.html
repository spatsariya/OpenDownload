v0.2.0 · CROSS-PLATFORM PREVIEW

A download for your device.

Choose your operating system. Desktop runtimes are included.
No account or subscription.

Windows

Windows x64. Open the installer and follow the setup wizard. Desktop and Start menu shortcuts are included.

Download MSI ↓

Unsigned preview. Windows may show an unknown-publisher notice.

macOS

Choose the build for your Mac’s chip. Open the DMG and drag OpenDownload to Applications. Built and startup-tested on macOS 15.

Apple Silicon ↓Intel ↓

Not notarized with Apple. macOS may prevent the app from opening.

Linux

x64 desktop, built on Ubuntu 22.04. For Ubuntu/Debian, install the .deb with sudo apt install ./OpenDownload-0.2.0-Linux-amd64.deb.

Debian / Ubuntu ↓Portable tar.gz ↓

For a per-user install, extract the archive and run ./OpenDownload/install.sh. Requires a graphical desktop and compatible system libraries; not every Linux distribution is supported.

Android

Android 10 or newer. Open the signed APK and allow installation from your browser when Android asks. Not distributed through Google Play.

Download APK ↓

This smaller native app uses Android’s download service for background transfers, progress, notifications, and opening files. It does not include manual pause/resume, segmented downloads, or speed controls. Long-press a row to cancel/remove it and delete its file.

Preview, not a finished product. Desktop builds run engine tests and packaged startup checks on each target OS. Android runs lint and an emulator download-integrity check. Coverage on real devices is still limited.
